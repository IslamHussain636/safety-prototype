# Third-party assets

`static/vendor/aframe.min.js` is A-Frame **1.5.0**, downloaded from [the official release asset](https://aframe.io/releases/1.5.0/aframe.min.js). The retained license is `static/vendor/AFRAME-LICENSE` (MIT). Bundled upstream notices remain in the distribution where present.

`static/vendor/Roboto-msdf.json` and `Roboto-msdf.png` are the A-Frame-hosted Roboto MSDF font assets from [A-Frame’s font directory](https://cdn.aframe.io/fonts/Roboto-msdf.json). The Roboto Apache 2.0 license is retained as `static/vendor/ROBOTO-LICENSE`.

Python dependency versions are listed in `requirements.txt`; their installed distributions retain their upstream licenses. No license is assigned here to the user's own code or proposal.
